이미 북마크를 추가하셨나요?+

최신 버전은 2.2.1입니다. 회차가 1화부터 시작하지 않는 소설도 저장할 수 있도록 고쳤습니다. 위의 ‘소설 저장’을 다시 추가해 주세요.

저장 중이었다면 먼저 일시정지하세요. 소설 목록을 새로고침한 뒤 새 북마크를 누르면 이어서 저장할 수 있습니다. 새 북마크가 작동하는 것을 확인한 뒤 예전 북마크를 지워 주세요.

  3. 3

    전체 회차 저장하기

    회차 수가 적힌 초록색 저장 버튼을 누르세요. 완료되면 한 개의 텍스트 파일(.txt)을 받습니다.

i
저장하는 동안 Chrome을 열어 두세요

컴퓨터가 잠자기에 들어가면 저장이 멈출 수 있습니다. 인증 화면이 나오면 회차가 열린 탭에서 직접 풀어 주세요. 인증이 끝나면 자동으로 계속 저장합니다.

다른 컴퓨터에서도

이 페이지에서 다시 시작하세요

새 컴퓨터에서도 이 페이지를 열고 북마크를 추가하면 됩니다. 저장하던 소설을 이어받으려면 백업 파일도 함께 옮겨 주세요.

다른 컴퓨터에서 이어받는 방법+
  1. 기존 컴퓨터의 저장 창에서 저장 범위·백업 → 복구 백업 저장을 누르세요.
  2. 받은 백업 파일을 새 컴퓨터로 옮겨 주세요.
  3. 새 컴퓨터에서 같은 소설을 열고 북마크를 누르세요.
  4. 복구 백업 가져오기로 파일을 불러온 뒤 큰 저장 버튼을 누르세요.

진행 상황은 컴퓨터 사이에 자동으로 옮겨지지 않습니다.

어떤 사이트에서 사용할 수 있나요?+

북토끼의 글로 된 소설에서 사용할 수 있습니다. 만화나 이미지로 된 회차는 저장할 수 없습니다.

다른 소설 사이트에서 작동하는지는 확인되지 않았습니다. 북토끼도 주소나 화면이 바뀌면 작동하지 않을 수 있습니다. 작동을 확인했던 주소는 sbxh9.com입니다.
